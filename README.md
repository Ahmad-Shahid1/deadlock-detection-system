Deadlock Detection System:

A Java program that reads process-resource relationships from input.txt, checks for circular waits, and prints the search steps and detection result.

Features:

Reads process-resource relationships from the input file.

Checks for circular waits.

Prints the search steps and detection result as text, not as a table or a drawn graph.

Running the Project:

You'll need a Java Development Kit (JDK) installed.

Provide your own input file named exactly input.txt and place it in the same folder as DeadlockDetection.java. The program reads this file to check for deadlock.

Use > or < to describe each process-resource relationship, one per line.

Open Command Prompt in that folder.

Compile:

javac DeadlockDetection.java

Run:

java DeadlockDetection
